# CTF-BTFly 2.7.9 宣传站

这是可直接部署到静态托管平台的零构建站点，不依赖 Node.js、CDN 或后端服务。

## 本地预览

在仓库根目录运行：

```powershell
python -m http.server 4173 --directory site
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

将本目录内的全部文件上传到静态站点根目录，确保 `index.html` 与 `assets/` 位于同一级。

## 内容口径

- 当前最新版按 `2.7.9 beta` 展示，对应 Windows x64 便携版；宣传正文聚焦完整产品能力，不突出维护级小更新。
- `1.3.1` 为开源版，具备基本功能，不含镜像一键导入和黑板模式。
- 历史 Docker 版用于迁移对照，当前 Windows 原生版不依赖 Docker Desktop 或 WSL。
